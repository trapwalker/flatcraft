# Бэклог тестового проекта (демо-страница)

Это **не** бэклог библиотеки-виджета (см. `BACKLOG.md` — там `MapWidget` и всё,
что вокруг него переиспользуемо). Здесь — house-keeping конкретно
`src/index.ts`/`src/layers.ts`/`docs/index.html` как тестового стенда: чем
удобнее и богаче тестовая страница, тем быстрее и увереннее проверяется каждая
новая фича виджета. Разделение уже предусмотрено в `BACKLOG.md`/`INFRA-5`
("виджет — отдельная переиспользуемая библиотека", core/demo split) — этот файл
живёт по ту сторону границы, которую `INFRA-5` формализует.

Тот же формат ID/чекбоксов/оценок, что и в `BACKLOG.md`, но со своим
префиксом — `DEMO-*`.

  **Разбор того, что есть у nakarte** (для справки, не всё стоит тащить один
  в один):
  - **Базовые подложки без ключа/ограничений ToU для тестового некоммерческого
    стенда** — можно добавить сразу, тем же паттерном, что уже есть у
    `tsFront` (`XYZTileSource` + URL-шаблон): **OpenStreetMap** (уже есть),
    **CyclOSM** (`{s}.tile-cyclosm.openstreetmap.fr`), **ESRI World Imagery**
    (спутник, `server.arcgisonline.com`, URL-шаблон нестандартный — `{z}/{y}/{x}`,
    не `{z}/{x}/{y}`, `XYZTileSource.buildUrl` уже переопределяем в
    `TMSTileSource` тем же способом), **OpenTopoMap**
    (`{s}.tile.opentopomap.org`, топографический стиль, читаемые
    надписи/горизонтали — хороший кандидат заодно и для проверки `ZOOM-12`
    "буст масштаба растровых тайлов", см. `BACKLOG.md`/"Открытые вопросы").
  - **Требуют API-ключа или отдельного решения по ToU** — не брать сейчас,
    отдельная задача, если вообще понадобится: **Yandex Map/Satellite**,
    **Google Map/Hybrid/Satellite/Terrain**, **Bing Satellite** (условия
    использования большинства из них не рассчитаны на встраивание в
    сторонний виджет вне их собственного JS SDK — юридически рискованно
    просто дёргать их тайловые URL напрямую, в отличие от OSM-совместимых
    источников); **OpenCycleMap**/**OSM Outdoors** (Thunderforest — нужен
    персональный API-ключ).
  - **Собственная инфраструктура nakarte, не переиспользуема "просто по
    URL"** — исторические топокарты СССР разных масштабов (`Topo 10km`,
    `GGC 2km`, `ArbaletMO`, `GGC 1km`/`500m`/`250m`, `Topo 1km`/`500m` и
    т.д.) раздаются с `tiles.nakarte.me` — это ЕГО собственный хостинг
    заранее нарезанных архивных карт, не публичный сервис общего
    назначения; брать эти URL напрямую — незаявленная нагрузка на чужой
    сервер без разрешения. Если этот класс данных когда-нибудь понадобится
    всерьёз — see `PROJ-1`/офлайн-геосервисы в "Видении" (`BACKLOG.md`), это
    большая отдельная тема (свой тайл-сервер/зеркалирование по
    договорённости), не пункт для демо-страницы.
  - **Интересные немедленно как эталон для будущих `VEC-*`/`LAYER-*`**, не
    сами тайлы, а МЕХАНИЗМЫ: `soviet-topomaps-grid` (векторная сетка границ
    листов карты поверх растра — хороший референс для `VEC-*` + billboard
    подписей), `Wikimapia`/`WestraPasses` (точечные маркеры с попапами —
    референс для `VEC-1`/`VEC-4`), `leaflet.control.layers.*` (адаптивная
    высота, минимизация, хоткеи на слои — идеи для `DEMO-1`/будущего
    `LAYER-*` UI, не обязательно копировать 1:1).

  **Предлагаемый минимальный срез для этой задачи:** добавить CyclOSM, ESRI
  Satellite, OpenTopoMap как новые `XYZTileSource`/`TMSTileSource` в
  `src/layers.ts`, завести под них слои и пункты в `LAYERS`/`ALL_LAYERS`,
  прогнать через `DEMO-1`-группировку (базовые подложки — радио-группа).
  **Зависит от: DEMO-1 (по месту, не по коду). Оценка: S.**
